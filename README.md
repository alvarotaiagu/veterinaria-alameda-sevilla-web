# Veterinaria Alameda · web

Web estática de Veterinaria Alameda (Alameda de Hércules, 41, Sevilla).

- `negocio.json`: datos de la clínica (teléfono, horario, servicios, equipo…).
- `marca/`: logotipo, isotipo y colores.
- `media/`: fotografías.
- `fuente/`: plantillas HTML; `node scripts/aplicar.mjs` genera las páginas.
- `node scripts/servir.mjs`: servidor local.

Mientras no se contrate, la web no se indexa en buscadores (`noindex`).
